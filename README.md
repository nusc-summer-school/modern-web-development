Modern Web Development NUSC Summer School 2025

Welcome to the Modern Web Development workshop for the NUSC Summer School 2025! This repository contains all the materials needed to build responsive and interactive web applications using JavaScript frameworks and modern development tools.

Workshop Overview
This workshop provides a comprehensive introduction to modern web development techniques and tools. Participants will learn how to build responsive web applications using HTML, CSS, and JavaScript, emphasising modern frameworks and best practices.

Learning Objectives
By the end of this workshop, participants will be able to:

Create responsive layouts using modern HTML5 and CSS3 techniques
Implement interactive functionality with JavaScript
Build single-page applications with React
Understand modern web development workflows and tooling
Implement a responsive design for various screen sizes
Work with REST APIs and async data fetching
Deploy web applications to production environments
Prerequisites
Basic understanding of HTML, CSS, and JavaScript
Familiarity with web development concepts
Experience with using the command line interface
A laptop with Node.js (18+) installed

Setup Instructions
Option 1: Local Development
bash
# Clone this repository
git clone https://github.com/nusc-summer-school/modern-web-development.git
cd modern-web-development

# Install dependencies
npm install

# Start development server
npm run dev
Option 2: Using CodeSandbox
You can also use CodeSandbox to work on the exercises without installing anything locally:

Go to CodeSandbox
Create an account or log in
Create a new sandbox with the React template
Import the exercise files from the GitHub repository
